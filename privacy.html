Privacy policy

Last updated: 10 October 2026

AI mail summary is a personal tool used only by its owner, Daan van Hulst, on his own Gmail account. It is not offered to anyone else.

Data accessed

With the gmail.readonly scope, the tool reads the sender, subject, date, labels and text of emails received in the last 24 hours. It never sends, modifies, labels or deletes email.

How data is used

The emails are summarised by a language model running locally on the owner's own computer. The summary is posted to a chat server on the owner's own home network. Email content is not sent to any third-party service, not sold, not used for advertising and not used to train AI models.

Storage

Email content is processed in memory and not stored by the tool. The daily summary is kept in the owner's private chat channel. The OAuth refresh token is stored locally on the owner's computer.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
